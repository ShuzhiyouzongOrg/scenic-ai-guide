来源 `map.visitorCenter` 与点位 ID 806“游客中心”相差约 322.22 m，两个值均保留，不静默修正。默认复位使用来源地图中心；定位失败不会使用有争议的游客中心点。

实现规则：

- 数据模型始终保留 `coordinateSystem`。
- GCJ-02 原值不覆盖；Leaflet/OSM 显示前只转换一次到 WGS84。
- 外部高德导航使用 GCJ-02，WGS84 输入先集中转换。
- `UNKNOWN` 坐标直接拒绝转换并进入审核。
- 转换测试覆盖正向、反向和二次偏移防护。
