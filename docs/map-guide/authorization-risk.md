# 授权、版权与外部服务风险

| 对象                          | 当前处理                               | 上线前动作                                                                       |
| ----------------------------- | -------------------------------------- | -------------------------------------------------------------------------------- |
| 两张完整手绘地图             | 由来源图块离线拼接并迁入目标静态资源；来源权利状态未知。 | 取得景区/设计方书面授权，确认可修改、分发和缓存。                                |
| 214 个封面与 31 个音频        | 仅保留来源清单，默认不加载来源 CDN。   | 确认图片、录音、表演者声音和文稿的网络传播及数字人再合成权；镜像至受控对象存储。 |
| 景点介绍与官方路线文案        | 保留来源，未冒充 AI 生成。             | 确认复制、改编、翻译和公开展示许可。                                             |
| 来源 `oc-api.lingshan.com.cn` | 未作为生产数据源。                     | 如需继续调用，签订接口使用、频率、数据处理和 SLA 约定。                          |
| OpenStreetMap 公共瓦片        | 仅作为可配置开发默认值。               | 大屏/生产流量使用自建或获许可服务，保留正确 attribution。                        |
| 720 云全景                    | 第三方 iframe + 外部打开降级。         | 确认账号所有权、嵌入授权、域名白名单、Cookie、全屏、陀螺仪和 SLA。               |
| 讯飞数字人                    | 沿用目标项目已有 SDK。                 | 核对形象、音色、外部音频驱动和并发授权。                                         |
| 外部地图导航                  | 使用高德 URI Scheme/Web URL。          | 核对商业使用条款和坐标说明。                                                     |

特别说明：官方音频没有 viseme 时间轴。讯飞外部 PCM 驱动与 Live2D 幅度驱动属于真实音频驱动，但不能在材料中表述为已获得官方逐音素标注。
