迁移脚本可重复运行：

```bash
cd server
npm run migrate:map-guide
```

官方路线默认读取 `server/data/source-snapshots/map-guide/official-routes.json`，生产运行不依赖来源接口。仅需人工刷新来源路线快照时执行：

```bash
node scripts/migrate-map-guide.mjs --refresh-routes
```

仅在授权确认后镜像全部媒体：

```bash
node scripts/migrate-map-guide.mjs --download-tiles --download-media
```

媒体下载并发限制为 4，输出目录默认 `server/data/map-guide-media` 且已加入 Git 忽略。上传对象存储后设置 `VITE_MAP_MEDIA_BASE_URL`。
