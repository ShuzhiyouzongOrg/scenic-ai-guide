# 目的地、摄影与到访记录的运行复测

2026-11-22，在本机 HBuilderX 5.24 的游客端和同仓测试 API 上操作。Chromium 和 WebKit 分别运行 390px 浅色与 320px 深色模式，深色组另开启大号字体与减少动态。测试数据保存在隔离的浏览器上下文。复跑命令见[浏览器验收](web-verification.md)，业务断言已加入[同一测试入口](../../../scripts/verify-visitor-web.py)。

| 输入与观察 | 通过条件及实测结果 |
| --- | --- |
| 打开灵山，切换拈花湾 | 热门栏目按有明确关联的官方路线计数。实测灵山梵宫入选四条、五灯湖广场入选三条、拈花塔入选两条；重复站点只算一条路线。同频时优先显示有登记摄影的景点。两个景区分别有游客中心租借点和手作体验馆入口。[灵山栏目](evidence/home-destinations.webp) |
| 点热门地点，读出实际图片宽度 | 梵宫、五灯湖广场与拈花塔的列表缩略图均解码为 160px 宽。点入梵宫和拈花塔后，请求 pages/spot/static 中各自的大图，均成功解码，宽度超过 320px。缩略图、详情图和当地窗口的景名对应。归属、加工、文件尺寸及许可可通过“我的 → 照片署名”或[资产记录](../assets/asset-management.md)核对。 |
| 让路线接口单独返回 503，再点重试 | 热门区域出现断路插画、可读的失败说明和重试动作；恢复服务后“拈花塔”重新出现。状态图在运行页面解码为 240px 宽。[深色失败态](evidence/home-route-error.webp) |
| 打开没有收藏的列表 | 显示折页地图与添加收藏说明。无图或网络失败时文字仍可独立表达操作。[首次收藏空态](evidence/favorites-empty.webp) |
| 浏览梵宫和拈花塔，只在拈花塔点“标记我已到访” | 返回列表，两个地点保留在最近浏览，手动到访只显示一处。打开该条并撤销，游览足迹恢复为空，拈花塔仍在浏览历史。沿用原浏览存储键，手动到访使用独立键，整个流程无需定位权限。 |

现有目录有 47 个灵山景点和 31 个拈花湾景点。本轮登记七处具体景点的实景摄影；未核实地点或权利的照片继续使用占位。游客可从对应卡片继续查看资料或打开地图。热门栏目反映官方路线覆盖次数，景区未提供客流统计。

四组运行记录保留每个页面的实测宽度、底栏边界、图标加载、脚本异常与接口状态。两种引擎各在两种视口通过。普通 Chromium 会话另在没有请求重写时访问 5173，首页向 5198 发起真实 HTTP 请求，景点接口返回 200，梵宫卡片出现。测试中的路线 503 是有意注入；云会话 503 的原因是本地服务缺少商业凭据。[本轮浏览器测量](evidence/home-followup-results.json) · [五页同一构建实拍](evidence/five-tabs.webp)
