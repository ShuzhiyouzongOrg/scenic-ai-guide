# 微信导游光球与电平条自测

## 测量方式

静音、轻声、正常音量各持续 2 秒。对照测试用固定频率和已知强度的 PCM 代替人声，以便跨版本重复。文中的 RMS 是数字音频相对于满量程的均方根幅度，不能换算为游客身边的声压。观察时同时记录光球外环和七根电平柱。静音时允许保留聆听状态的呼吸，真正没有读数时应显示「未提供音量」。

## 微信构建产物的定量结果

在同一组 16 kHz 单声道、220 Hz 合成输入上执行实际编译出的录音适配器、状态管理、光球和电平组件。共 94 个分片，最后一个为 1536 字节，跨越音量切换边界的分片照常保留。表中数据取自各段结束时交给微信视图的绑定值。这个测试使用确定性的录音回调和时钟，实际开发者工具的屏幕取证另记。

| 两秒片段 | 段末实测 RMS | 修前柱高 | 修后柱高 | 修后光球平滑幅度 |
| --- | ---: | ---: | ---: | ---: |
| 静音 | 0 | 3 px | 3 px | 0 |
| 轻声 | 0.017655 | 3 px | 7 px | 0.219 |
| 正常音量 | 0.225704 | 7 px | 16 px | 0.785 |

续测时从正常音量切到持续数字静音，960 ms 后七根柱均为 3 px，声音外环熄灭。另一轮保持录音开启但停止送帧，512 ms 后收到一次「无读数」，2 秒后仍为聆听状态。恢复送帧后，下一次光球更新重新出现声音外环。停止录音后送入迟到分片不会改变页面状态。[修后逐帧读数](evidence/wechat-orb-self-test/pcm-path.json)

## 本次发现与修正

原先电平条直接把线性 RMS 换算为 3–20 像素高的柱。轻声可能与静音同为 3 像素。组件还只在响度数值变化时滚动历史，相邻分片完全相同时不会推进。说完后连续送入 960 ms 的零值分片，修复前七根柱仍为 7、7、7、7、7、7、5 像素。现在复用光球已有的开方显示增益，按有效采样次数推进历史。[修前读数](evidence/wechat-orb-self-test/pcm-path-before.json)

微信录音已开始、但后续完全不返回分片时，原实现会一直保留最后的响度。现在录音器在收到过有效分片后监测回调间隔，超过 512 ms（当前请求的 8 个分片时长）给界面发一次「未提供音量」。录音继续，下一个真实分片恢复测幅，结束、取消或中断后解除检查。分片中读到的零值仍表示真实数字静音。

复跑编译产物测量时，运行 `node scripts/verify-wechat-audio.mjs --mp-build <微信构建目录>`。核对轻声高于静音、正常音量高于轻声，以及重新进入持续静音后所有柱都能回到底线。结束录音后确认电平回到「未提供」，取消后不产生识别请求。[微信适配器](../../../visitor-app/services/wechat-audio.js) · [电平组件](../../../visitor-app/components/guide-level-meter/guide-level-meter.uvue)

H5 补充对照用合成 WAV 作为 Chromium 的输入设备，点击导游页中央麦克风并读取渲染后的实际柱高。典型采样处，修复前静音、轻声、正常分别为 3、3、6 像素；修复后分别为 3、6–7、14–15 像素，回静音后全部恢复为 3 像素。[浏览器采样](evidence/wechat-orb-self-test/h5-control.json)

## 已运行的宿主与取证边界

- **微信开发者工具。** 修复前的包通过中央麦克风开始录音，显示「正在聆听」、计时和电平条，点击取消后退出。宿主回报 133 个分片。开发者工具提示录音格式与移动端有差异，此轮未确认分片编码和可控音量，因此不以其峰值评定三段输入。[微信模拟器收音实拍](evidence/wechat-orb-self-test/devtools-listening.webp)
- **最终微信包。** 上表读取自最终小程序的实际编译代码，由测试驱动传入 PCM 和推进时钟。桌面操作中途被按键停止，最终包在开发者工具内的三段连续录屏尚未取得。最终微信主包本地预检为 2,064,723 B，低于 2 MiB。
- **实际渲染的三段画面。** 浏览器补充测试取自最终 H5 包的真实导游页和受控输入设备，保留了同一舞台位置的三张截图。[H5 三段画面对照](evidence/wechat-orb-self-test/h5-listening.webp)
- **物理手机。** 当前电脑未发现已连接且可控制的 Android 或 iPhone。实际手机麦克风的收音强度、微信真机返回的分片及屏幕逐帧表现待验。

HBuilderX 5.24 完成微信、H5 以及 Android 和 iOS 共享组件的本地编译。后两项只覆盖编译，未启动 MuMu 或 iOS 设备。本轮未运行鸿蒙。
