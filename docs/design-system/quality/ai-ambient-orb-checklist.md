# 导游舞台与语音状态球验收

最新一轮已执行的项目、截图、光球测量和设备缺口见[沉浸式导游验收记录](ai-guide-immersive-verification.md)。

本轮可复查的宿主结果分为[H5 新页面与轻声实录](ai-guide-immersive-web-verification.md)、[组件独立帧差](evidence/ai-orb-motion-perception.json)及[真实音频流、音频文件与模型桥](evidence/guide-audio-runtime.json)。

记录构建版本、产物目标、基础库或系统版本、设备/模拟器、视口/显示倍率、主题、语言、动态偏好、音源与服务类型。下表是本次改动的实际运行检查方法。每个结果用“实测通过／复现缺陷／未测及原因”记录。历史录屏可辅助对比；采用新页面截图与运行记录判断新实现。

| 检查 | 怎样操作和取证 | 通过条件 |
| --- | --- | --- |
| 布局与层级 | 首次进入语音模式，检查 320 和常规宽度、深浅色、大字体、三种语言。再打开键盘、滚长历史及返回舞台。 | 人物、字幕和操作不被球、底部 tab、软键盘或状态栏遮挡。焦点和点按位置跟随可见控件。 |
| 状态机 | 记录授权待定、确认录制、结束发送、回答到达、开始发声、暂停/恢复、取消、失败与重连的宿主事件及界面。触发禁用和不可观测音源。 | 八个公开态可解释。播报/收音状态与回调一致，无假装正在聆听；RECONNECTING 有真实证据。字幕在段边界改变；无逐字猜测。 |
| 实测电平 | 将可控静音、不同幅度的固定音频送入**实际音频路径**，记录时间窗、来源、owner 与归一化数值。另以真实设备和麦克风复核。 | 0 为真实静音，输入升高后电平有界地增大；缺失返回 -1。注明实采麦克风、合成测试音频、已解码旁路或仅状态节律。SDK 事件、合成口型和截图不能证明声压测量。 |
| 暂停与中断 | 边录边取消，网络未回时切页，中段暂停/恢复、打断后快速提新问题。触发过期授权、上传、TTS、SDK 与采样回调。 | 无幽灵上传/重复声音；已取消的字句和电平不会更新下一轮。返回时初始状态正确，音频资源和计时器数量可验证。 |
| 可见性与减动 | 切换项目减动及宿主系统偏好。在语音、文字、后台、卸载、重入间交替；拍摄静态状态和两张可比较运动帧。 | 低动态路径冻结装饰；没有漏关监听或计时器。系统偏好未知的平台标明项目设置实测范围；读屏不逐帧报数。 |
| 形象与声音回退 | 分别进入讯飞/本地舞台，模拟模型或云服务失败；微信检查人物缓冲区、点击区域及返回位置。 | 真实 ready/播放/结束事件独立，模型失败可读文本和可用声音继续；静态立绘与角色吻合。模拟服务不列为商业云验证。 |
| 健康与性能 | 同一设备对比改动前后空闲、收音、模型发声各一段，记录采样时长、计时器、帧时间/掉帧、内存及调度停止后的变化。复算生产包体。 | 有真实采样才报告 FPS/功耗，不拿单次 onShow 当帧率。动画退化不影响按键、滚动、模型或语音；依赖/资源与主包余量可追踪。 |
| 构建与无障碍 | H5 双引擎、微信 WCC/WCSC 与正式 AppID 宿主、Android 实际运行、iOS 可用工具；分别记录构建、模拟器及真机。 | 各层证据独立，运行日志无新增阻断错误。检查图标与文案、44px 命中、焦点、语义标签、低对比状态和键盘替代。本轮排除鸿蒙运行。 |

维护检查运行 `node scripts/design-tokens.mjs --check`、`python scripts/check-design-system.py --codex` 与快照校验。通过正式服务验证之前，区分本地请求、模拟云回调和已授权商用服务。截图不留账号、密码、开通凭据、私有音频或会话标识。[设计系统发布核对](release-checklist.md) · [此前语音与地图](guide-verification.md) · [能力基线](../engineering/ai-ambient-orb-feasibility.md)

变更导游底栏后，逐项复测按压期间播放自然结束、上滑取消、点击发出、导航离页清理，确认字幕行打字、页头历史和播报控制可达。与其他四页系统栏逐项对齐，在标准与减少动态模式分别记录进出动画。[五格导航实测与复跑](guide-navigation-web-verification.md)
