# 基础：视觉、响应式与无障碍

参照[HIG-01–06、SRC-01–03](../references/source-index.md)。打开首页时游客先要辨认景区和下一步行动；看地图时地图占最大面积；进入 AI 时停止录音或播报的按钮始终可达。照片表现旅行氛围，操作区保持素色，品牌标志沿用原项目。操作优先级依次为本屏主任务、替代操作、说明。审核时遮住图片仍应能完成主任务。

## FND-01　颜色及明暗

下表为视觉角色，精确值以 visitor-app/design/tokens.json 为准。SCSS 使用 $sg- 前缀；脚本中的原生属性或 Rice 图标通过 themeColor(name) 获取实际色值。根元素绑定 themeClass 并引入 sg-themes。使用主题事件适应当前工程中的 Vapor。原生导航取 theme.json 的同源配置。

| 角色 | 用于 | 对比与边界 |
| --- | --- | --- |
| primary / on-primary | 主按钮、已选图标及其标签 | 主按钮实底与专用前景成对使用，暗色的主按钮采用深前景 |
| secondary / accent / ai | 次级信息、目的地强调、语音/助理身份 | AI 的色彩只作辅助，以具体文字说明录音/等待/播放 |
| background / surface / inset | 页面、卡片/对话、嵌套选择区 | 平面间通过留白与分隔区分；地图面板使用不透明表面 |
| text / muted | 正文、辅助正文 | 普通文字至少 4.5:1，大字至少 3:1。两种主题都在最终背景上测量 |
| border / divider | 控件边界、内容分组 | 承担关键识别时用足够强的描边或文字；细线仅作辅助 |
| success / warning / error | 已保存、权限提示、可恢复失败 | 同时给出图标/文字和用户能执行的操作 |
| hero / on-hero | 固定深色摄影说明底 | 未知照片使用实色承托；主题改变仍保持标题可读 |

## FND-02　字体与内容优先级

系统中文与拉丁字体由宿主选取，保留原生字形回退。项目字号档位为标题 32、分区 22、卡名 18、正文和按钮 16、说明/标签 14、短元数据 12 个逻辑像素。标题使用 600–700；正文采用常规字重。站点编号、时长和时间用宿主数字，在窄栏为多位数留宽。按钮长文改短动作词，错误原因和语音反馈允许折行。避免固定正文容器高度；多行简介可截断时提供详情入口。

浏览器支持页面缩放；原生字号是否跟随系统须在宿主检查。正常、放大、最长翻译各做一次：重看取消录音、路线保存、返回和登录，任何可操作标签被裁掉即不通过。技术限制记录到平台表。

## FND-03　布局、密度与层级

4px 为基础间距。图文间 4/8，行内与控件 12，普通卡内 16，页面横向 20，分区 24/32。圆角 8、12、20 分别用于小图块、常规卡、重点媒体，胶囊仅用于按钮和短选项。内容卡通过实色与边线界定；地图浮层按需要用一层阴影，文字与整页背景不叠多重投影。浮动控件要有地图数据和背景两侧都可见的轮廓。

五页共用系统底栏；安全区只由一层容器负责。自定义标题用 design/layout.uts 的 useScenicInsets() 获取窗口状态栏与安全区，在 onReady、onShow、onResize 重算；微信以菜单胶囊底缘为下界。输入区绑定可用窗口；键盘伸出时验证底部动作仍能触达。320/390/430 逻辑像素宽度、横向、系统大字号下检查：列不足时折行或垂直排布，地图保持独立手势区，首页仅推荐卡允许水平浏览。避免把整页缩成固定截图宽度。

## FND-04　选择与可操作性

独立操作区最小 44×44，Android 高频操控优先 48。图形本身可仅有 20–24。错误、录音、选中和失效状态兼有文字；选中附勾或标签，不能只看颜色。读屏按视觉阅读顺序，一张可点卡只朗读一个明确动作，纯装饰图层不抢焦点。拖动操作也给按钮替代。审查使用系统读屏逐项到主按钮，并用按钮完整走一遍排序或地图缩放。

### 大号字体

“我的 → 大号字体”保存本机偏好。打开后五个核心页面的语义字号放大 1.25 倍，按钮与地图仍使用独立热区。返回首页、切换语言并重开应用，检查标题和按钮仍可读、文本换行后仍可点击。H5 另支持浏览器手势缩放。
