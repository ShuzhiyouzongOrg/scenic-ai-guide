# 摄影、裁切与图片反馈

| 规则 | 场景与实施 | 验收 |
| --- | --- | --- |
| IMG-01 | 目的地 Banner 以 16:9 母版供等比裁切；首页视口以固定高度预留，拍摄主体放在中心安全区域。照片下方使用 hero/on-hero 实色文字区。两大目的地切换时同时替换地名和照片。 | 320、390、430 宽度查看主体；即使关闭图片，地名与地图入口仍清晰。 |
| IMG-02 | 景点卡保留独立缩略图区，使用 aspectFill，未登记图或加载失败退为相同尺寸的点位图标。匹配具体 spot ID 后才能展示照片。详情可以使用同一张批准母版。 | 检查 LS-006 的九龙灌浴画面、一个无图点位、失效文件、慢网与冷启动；均能打开正确详情。 |
| IMG-03 | 账号头像使用 aspectFill 和统一回退；数字人采用完整人物构图和原引擎资源。上传仅由用户主动触发，遵守 5 MB 限制。 | 断开头像地址，仍显示身份与编辑入口。更换图片失败后保留可操作页面。 |
| IMG-04 | 生成插画标明用途，功能卡只在实色区承载标题与箭头。空、错分别使用包内折页图和路标图，重试和说明留在操作区。加载使用静态骨架。 | 图片未就绪时用户仍能进入 AI 或行程；减少动态下加载占位保持静止。见[状态资源与验证](generated-illustrations.md)。 |

移动摄影按用途生成 WebP。主视觉使用 780px 图，列表缩略图使用 160×124，详情子包保存保持构图的较大版本。构建时只携带衍生图；避免打包全尺寸原片。可复用同一包内路径由宿主缓存。新增远程媒体应先完成授权登记，定义受控 HTTPS 地址、版本化缓存、失败占位及重试条件。界面不将完整网络地址作为错误文案。

来源与规则范围见[资产登记](asset-management.md)与[首页摄影登记](../pages/home.md)。
