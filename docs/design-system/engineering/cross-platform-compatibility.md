# 渲染宿主与跨端验收

依据 [SRC-02、HIG-02–08、MOT-03–05](../references/source-index.md)。`visitor-app/manifest.json` 指定 Vue 3、Vapor 字节码目标和样式隔离 2。Web 端实际使用 HBuilderX 5.24 的 VDOM 渲染器。UTS、地图、收音及数字人分别经过宿主实现，代码共享不能代替对应宿主上的测量。

## 共用边界

| 检查 ID | 实施方法 | 通过条件 |
| --- | --- | --- |
| PLAT-01 布局与安全区 | 保留宿主 tabBar。自定义页头从状态栏/胶囊下方开始。每个边缘由一层布局负责；H5 的 wrapper 已减去标签栏和底部安全区，在 Web 模板中消除额外的 body 伪元素占位。 | 点击首尾控件、滚到最后一条；页面底边接标签栏顶边，屏幕和页内卡片均无意外横向滚动。地图/横向推荐条可在自身范围滚动。 |
| PLAT-02 主题 | 页面根绑定 `themeClass` 并引入 `sg-themes`。命名颜色供 SCSS 使用；UTS 给原生/Rice 属性传 `themeColor` 返回的具体颜色。tabBar 使用由同一 token 生成的 theme.json 与各主题 PNG。 | 冷启动和运行中切换均切换文字、表面、选中图标；至少比较一个嵌套组件和原生标签栏。授权/系统弹层由宿主管理。 |
| PLAT-03 文字与操作 | 统一逻辑像素档位，保留系统字体。文本按钮随内容换行；禁用、选中、网络错误都给可读文本。滑动排序提供点按替代。H5 viewport 允许手势放大。 | 在最窄宽度选择最长语言并放大文字，点击目标的边缘，测试默认/忙碌/禁用；VoiceOver/TalkBack 真读验证单独记录。 |
| PLAT-04 动效 | Web 同时考虑系统 `prefers-reduced-motion` 和用户开关；Android 在冷启及再次显示读取 ValueAnimator，原生桥缺失时使用静态反馈。iOS/Android 通过 UTS 在回前台重读系统值，桥读取失败取静态；微信新装缺少系统读数时采用轻量反馈，优先恢复手动设置。固定录音/播放状态取 SDK 回调；和布局无关的过渡用透明度或小位移。 | 系统选 reduced 后，应用不能强制恢复装饰位移。停止、撤销、切 tab、回到前台不重播旧事件；直接手势仍可操作地图。 |
| PLAT-05 地图及数字人 | 地图几何和 SDK 标定常量根据数据维护。复用原生 map、微信 canvas、App WebView 的条件分支，各自拥有手势；面板保留显式展开、取消和关闭。 | 切景区后卡片、路线、选点一致；缩放过程中不误选。网络无凭据和权限禁用给真实降级提示。云端成功、原生定位和实际音频需要独立结果。 |
| PLAT-06 减少平台耦合 | 浏览器 DOM/媒体查询放在 `#ifdef WEB`；第三方 UTS 模块保持边界；原生布局使用受支持的 flex/尺寸，避免把浏览器的 全局选择器、滤镜或 drag/drop API 用于其他端。 | 生成物里没有跨端误入的 DOM API，目标平台各自编译。静态检查、编译、首次运行、真实设备交互分别登记。 |

手绘地图定位涉及本地坐标标定，视觉资源不得替换为任意便于裁切的底图。API 鉴权和环境配置保留于配置及服务层，QA 使用临时内存会话。验证来源见[真实浏览器记录](../quality/web-verification.md)、[发布核对表](../quality/release-checklist.md)与[原工程鸿蒙环境记录](../../harmony-development-environment.md)。
