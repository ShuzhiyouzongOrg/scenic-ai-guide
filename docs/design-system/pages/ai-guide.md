# AI 导游

入口为[AI 导游页面](../../../visitor-app/pages/ai-guide/index.uvue)。默认以语音和数字人舞台为中心，字幕紧邻当前话轮，底部主操作可开始或结束讲话。能量球辅助识别状态。游客可切换文字或查阅历史，在模型失败、麦克风不可用或关闭声音时仍能提问。语音与文字沿用同一景区、会话和引用资料。

从四个普通根页使用系统第三项进入导游。导游页内的中央语音操作与其他四个目的地共用底栏。页头的对话记录入口查看历史，字幕行的打字入口可随时恢复文字问答，暂停、继续、停止和取消仅在有适用操作时出现。[五格导航契约](../components/navigation.md) · [组件职责](../components/ai-guide-components.md)

详细规格分为[舞台与控制组件](../components/ai-guide-components.md)、[会话操作](../interaction/ai-guide-interaction.md)、[导游动效](../motion/ai-guide-motion.md)、[渲染与语音架构](../engineering/ai-guide-architecture.md)及[球体组件](../components/ai-ambient-orb.md)。本页原媒体状态 RECORDING、PROCESSING、RESPONDING、PLAYING 等继续表示业务进度；视觉层由[状态投影表](../interaction/ai-ambient-orb-interaction.md)区分收音、思考、播报、禁用和取消。

## GUI-AI-01　问答与形象

保留输入、建议问题、引用资料、历史会话、确认清除以及地图带入的问题。舞台下显示当前话轮字幕，历史面板按到达顺序列出问题和回答，包括可选择的正文、来源与回听按钮。只为同一个问题发起一次请求。右上设置中的自动播报偏好影响后续回答，操作区的停止用于当前回答。

App 保留云端讯飞与 Live2D 两个 WebView 入口。微信保留原生 `scenic-live2d` 以及滚动停稳后的定位。页面加载、SDK 就绪、开始发声是三个不同事件。仅获得页面加载回调时显示连接状态。云端资源错误按原逻辑区分顶层页面失败和子资源可恢复警告，文字提问应始终可用。

微信的形象区域以滚动内容中的真实插槽为准。组件可见且其实测宽高与插槽一致时，才用 CSS 尺寸乘设备像素比创建绘制缓冲区。滚动和切离标签暂停绘制，重显或旋转屏幕后重新核对缓冲区尺寸。页头在 Cubism 完成模型和纹理绑定、运行绘制且缓冲区尺寸匹配后收到 `modelready`，再显示“Live2D 模型在线”。布局测量、资源超时或渲染失败会触发 `modelerror`，显示不可用并保留同一形象的静态立绘。先进入减动模式时不初始化引擎；显示过动态形象后切为减动，则隐藏画布、取消动画帧并保留上下文。返回标准模式时继续使用同一画布。完整卸载页面时释放上下文，随后重新初始化框架须复用 Core 的日志回调槽。业务问答与宿主音频仍可操作。

## GUI-AI-02　语音状态与操作

| 状态 | 证据与可见反馈 | 可执行动作及退出条件 |
| --- | --- | --- |
| IDLE | 麦克风未开启，面板提示可提问 | 输入、发送、开始录音。等待系统权限时禁止再次开始 |
| RECORDING | 录音器 start 已确认，麦克风标识和“正在录音”文本同时出现 | 停止并发送，或取消。取消、离页均丢弃本次录音，不上传 |
| PROCESSING | 收到合法录音或文本，服务请求尚未完成；显示识别/检索文本 | 保留文本输入草稿，锁定重复发送。成功写入消息；失败进入 ERROR |
| RESPONDING | 答案已显示，当前音频在合成、解码或等待数字人接受 | 可打断。仅由音频 onPlay 或桥 speaking 进入 PLAYING |
| PLAYING | 宿主音频或已选数字人报告播放；显示正在播报 | 打断所有引擎。宿主音频另提供暂停。自然结束时播下一段或返回空闲 |
| PAUSED | 宿主 InnerAudioContext.onPause 已确认 | 继续在同一时间位置播放或停止。当前分段和队列索引保留 |
| ERROR | 展示可理解的原因，如麦克风未授权、网络不可用、音频播放失败 | 保留已生成的文字，可重试操作或继续文字提问 |

App 的两条数字人宿主桥公开 speak 和 interrupt。仅显示经当前引擎验证可用的操作。原生端暂停/继续复用同一个 InnerAudioContext。浏览器使用 HTMLAudioElement 的 playing/pause/ended 事件，并处理 play Promise 中的正常中断。两个实现恢复时都保留原 src。微信通过相同宿主音频驱动原生形象；浏览器仅在支持媒体采集且授权后开始录音。没有可用采集器时保留文本输入。服务端接受 MP3，或 8/16kHz 单声道 16bit PCM/WAV。不得把浏览器录到的 WebM 直接标记成 WAV。

## GUI-AI-03　中断与动态效果

停止、关闭播报、切换形象、离开页面均可使旧语音失效。异步 TTS 的旧结果不得在新回答、已静音或后台页面中突然开始播放。用户切至其他标签时取消待授权请求并释放采集；卸载时释放播放器、定时器和浏览器的音轨。减少动态效果时使用静态形象或静止状态标识，保留录音/播报文字反馈。形象不能挡住输入和停止操作。

## 验收路径

**GUI-AI-04** 语言取自个人中心。当前语言控制页面状态、错误、权限说明、建议和提交给服务端的回答语言。简体使用 `zh-CN`，繁体使用 `zh-TW`，英文使用 `en`。已存储的聊天记录、景区提供的人名和引用标题保留原文。录音计时为分和秒。讯飞 IAT 按界面选择英文 en_us 或中文 zh_cn；繁体口语按普通话识别，回答保留 zh-TW。英文和繁体欢迎卡说明录音所用语种与既有导游音色。系统权限窗口的语言由设备管理。[协议与实测](../quality/guide-locale-verification.md)

1. 在输入键盘开启时提问，再从地图送入一条问题；核对各一份消息、无双重播报、来源可读。
2. 依次允许和拒绝麦克风；区分“取消”和“停止并发送”，离页、权限弹窗中切走、快速双点都不得产生隐形上传。
3. 宿主音频播放多段回答，在中段暂停、等待、恢复、打断，确认队列不会重播前一段。让服务端延迟 TTS，在等待时静音，稍后不应听到声音。
4. 云形象和 Live2D 各检查一次 speaking、idle、interrupt，与现场可听到的声音核对。断网、无权限时仍可查看文字。设备缺席时在发布表标注待验。
5. 微信先在减动模式进入 AI，然后到个人中心切回标准动效，返回 AI 并滚回形象区域。观察模型从加载到在线，检查人物面部、衣着的纵横比及重显后的细节。另测直接冷启动、改变视口、滚动出入舞台和不可用时的静态反馈。
