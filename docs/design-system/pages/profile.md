# Profile · 我的

个人页组织账户身份、设备上的行程与收藏、导览偏好及其他设置。收藏、最近浏览和手动标记的到访分别保存在本机。打开详情只更新最近浏览；主动点“标记我已到访”才计入游览足迹，点“撤销标记”可以移除。保留旧版浏览记录及原键，不将浏览记录迁移为到访。

| ID | 决策与理由 | 工程约定 | 验收 |
| --- | --- | --- | --- |
| PROFILE-01 | 游客与登录状态都能读到当前身份及可执行操作。 | 缓存先显示，已有 token 再刷新 profile。头像打开现有系统选择器；上传中防重复，5 MB 限制与失败反馈保留。退出使用系统确认。 | 清空存储首次进入；登录、更换、取消选择、拒绝权限、图片过大、退出取消，各自均有确定结果。 |
| PROFILE-02 | 计数与入口相邻。 | 收藏、手动到访和最近浏览分别读取本机，行程来自真实 session 保存记录；网络错误时显示未知状态或上一次成功值。共用菜单行，避免用颜色区分服务。 | 有收藏后点击记录，内容与计数一致；网络断开时不虚增行程。 |
| PROFILE-03 | 景区、数字人与语言偏好应在当前行立刻反馈。 | 复用原生 action sheet。仅列出可用数字人，微信分支保留 Live2D；语言沿用原有简体、English、繁体存储和原生 Tab 标签更新。 | 选择两景区后返回地图/首页验值；三种语言不发生操作区重叠；微信不能选中不可用引擎。 |
| PROFILE-04 | 服务和设置分组，说明由相邻静态文本提供。 | 复用带标题、描述、图标及前进箭头的行；长文本允许换行。保留反馈、隐私说明与关于入口。 | 320 逻辑像素宽、长用户名、繁体与英文逐项点击；系统返回仍在个人页。 |

## 来源与适配

PROFILE-01/03 实施 Apple HIG 的系统选择器与用户控制；PROFILE-02/04 以项目 auth、session、visitor-activity、guide-preferences、locale stores 为事实来源。不要添加后台没有记录的里程、等级或签到状态。

参考 [Apple HIG Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables) 与 [Apple HIG Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts)。

### 大号字体

“我的 → 大号字体”保存本机偏好。打开后五个核心页面的语义字号放大 1.25 倍，按钮与地图仍使用独立热区。返回首页、切换语言并重开应用，检查标题和按钮仍可读、文本换行后仍可点击。H5 另支持浏览器手势缩放。

**PROFILE-05**　以[本机活动存储](../../../visitor-app/stores/visitor-activity.uts)为来源，区分收藏意图、阅读行为和游客亲自标记的到访。打开、标记、重载后撤销同一景点，确认浏览记录仍显示，个人页到访计数与手动标记一致。操作不请求定位，也不上传坐标。
