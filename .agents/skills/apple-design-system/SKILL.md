# apple-design-system

把 Apple HIG 适配到 Scenic AI Guide 的游客端视觉层级、主题、无障碍和导航。修改主要页面布局或品牌样式时使用。

开始前打开[项目知识索引](references/project.md)，按任务读取其中规范及对应页面源文件。

从当前任务的页面规范列出首要操作与返回路径。确定照片与标题关系、系统栏安全区及最小热区。只把有技术依据的规则写入项目实现。

分别检查两种主题、最窄屏、放大文字、纯文本反馈及连续返回。

保持项目服务、平台架构与用户资料的原有契约。对于超出宿主能力的规则，在发布核对表标记实际验证范围。
