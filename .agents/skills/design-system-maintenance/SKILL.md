# design-system-maintenance

更新 Scenic AI Guide 的设计知识库、候选设计 Skill 来源、许可证、离线归档或生成的 Token 时使用。

开始前打开[项目知识索引](references/project.md)，按任务读取其中规范及对应页面源文件。

固定新旧 SHA，比对文件、指向和许可证，按规则 ID 写入变化及适配。同步源码生成物、页面说明和相关 Skill。未获授权的材料只链接和独立总结。

运行离线归档校验、Token --check、文档相对链接检查及 Codex skills/list；至少调用一个变化的工作流。

保持项目服务、平台架构与用户资料的原有契约。对于超出宿主能力的规则，在发布核对表标记实际验证范围。

提交变更时在项目规范中定位变更涉及的规则 ID，核对原始章节、适用面、实际调用点与验收。若涉及按压或减少动态，在本机 H5 跑动效偏好回归，记录宿主、开关、终态与中断结果。
