# mobile-ui-audit

审查 Scenic AI Guide 移动页面的实际源码、视觉、跨端可操作性和质量证据，编写可复现的基线或发布审计。

开始前打开[项目知识索引](references/project.md)，按任务读取其中规范及对应页面源文件。

从 pages.json 追到页面、组件、API 及各端的条件编译。把观察结果与设备、操作步骤、具体状态和源码对应。检查真实网络失败、资源来源及业务状态。

区分源码检查、编译、浏览器、宿主模拟器与真机结果；为每个未验证结论记录原因及复测方法。

保持项目服务、平台架构与用户资料的原有契约。对于超出宿主能力的规则，在发布核对表标记实际验证范围。
