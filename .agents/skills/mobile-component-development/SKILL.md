# mobile-component-development

在 visitor-app 创建或修改共享组件、表单、媒体卡、状态面板及其 UTS 接口时使用。

开始前打开[项目知识索引](references/project.md)，按任务读取其中规范及对应页面源文件。

查同类组件、Rice 源码和所有调用方。复用可用实现，在组件边界用 props 和事件表达动作；组件内声明语义 Token。保留点击/禁用和失败状态。

编译真实页面调用方，检查缺图、长翻译、连点、主题、读屏与平台条件分支。

保持项目服务、平台架构与用户资料的原有契约。对于超出宿主能力的规则，在发布核对表标记实际验证范围。

提交变更时在项目规范中定位组件 CMP、交互 INT规则 ID，核对原始章节、适用面、实际调用点与验收。若涉及按压或减少动态，在本机 H5 跑动效偏好回归，记录宿主、开关、终态与中断结果。
